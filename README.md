# Weather App

A responsive weather application built with **React**, **Vite**, and **Tailwind CSS**. The app retrieves weather data from an external API and presents current weather information through a clean and responsive interface.

This project was developed as a hands-on opportunity to improve my experience with **React** and learn **Tailwind CSS** in a practical application.

## Technologies

* React
* Vite
* Tailwind CSS
* JavaScript
* REST API

## Features

* Search for weather information by location
* Display current weather conditions
* Responsive layout for different screen sizes
* Integration with an external weather API
* Dynamic presentation of weather data

## Future Improvements

Some improvements I plan to implement include:

* Add a map or location-based image representing the searched area
* Replace static weather icons with animated weather conditions
* Improve the overall user interface and user experience
* Add additional weather information and forecasts

## Purpose

This project is part of my software development portfolio and demonstrates practical experience with **React, API integration, responsive web development, and Tailwind CSS**.
